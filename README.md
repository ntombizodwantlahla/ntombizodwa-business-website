# Ntombizodwa Ntlahla — Portfolio Website

A responsive personal portfolio website introducing Ntombizodwa Ntlahla, an ICT in Business Analysis graduate based in Pietermaritzburg, KwaZulu-Natal.

## Features
- Professional introduction and profile
- Business analysis, web development and technical support capabilities
- Selected projects with live links
- Education, bootcamp experience, technical toolkit and certifications
- Availability, work location and rate expectations
- Direct email and telephone contact links
- Responsive navigation for mobile and desktop

## Built with
HTML5, CSS3 and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. GitHub Pages will publish the site and show its URL in the Pages settings.
